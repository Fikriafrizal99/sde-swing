# Live Test Guide — SDE Swing V1.6.1

1. Buka `RUN_SDE.bat`.
2. Dari Maintenance, jalankan Install requirements dan Test Telegram.
3. Jalankan Market Outlook, Post Market, dan Final Watchlist satu per satu dalam mode Preview terlebih dahulu.
4. Pastikan Broker Summary dan Broker Raw tanggal yang sama tersedia untuk pengujian Final Watchlist lengkap.
5. Cek hasil melalui `CHECK_SDE_STATUS.bat` dan folder preview.
6. Setelah valid, generate XML Task Scheduler baru melalui menu Maintenance.
