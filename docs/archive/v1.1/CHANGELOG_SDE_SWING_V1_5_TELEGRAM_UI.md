# Changelog SDE Swing V1.5 Telegram UI

## Added

- Centralized professional Telegram UI formatter.
- Seven scheduled Swing report formats.
- Entry readiness display.
- Human-readable data warning impact.
- HTML-safe dynamic values.
- Asia/Jakarta time formatting.
- Telegram UI unit tests.
- Scheduled preview package.

## Changed

- Scheduler reports now use the centralized formatter.
- Legacy/full manual reports now use the same formatter.
- Telegram parse mode is configurable and defaults to HTML.
- Post-market 16:30 reports are explicitly labeled preliminary technical.
- Public signal recap uses unique final symbols.

## Unchanged

- Technical scoring.
- Broker scoring and fusion.
- Decision engine.
- Entry and exit calculations.
- Swing/Day Trade pipeline separation.
