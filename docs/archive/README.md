# Documentation Archive

This directory contains historical SDE Swing documentation retained for audit,
release traceability, and migration context. Archived files are snapshots of
their original period and must not be treated as current operational guidance.

Use [`../README.md`](../README.md) for current documentation.

## Collections

- [`v1.1/`](v1.1/) — legacy guides, changelogs, implementation reports, and validation evidence from earlier releases.
- [`v1.7/`](v1.7/README.md) — stabilization, Phase 2/Stage 3, audit, and pipeline evidence organized during the V1.7.1 documentation cleanup.

Archived documents are retained rather than deleted. Runtime and release checks
may still reference specific governance evidence by its archive path.
